# Afterword · 听完，再聊

在自己的电脑上运行的英语听说练习工具。导入感兴趣的英文素材，与 AI 实时聊天，再回顾值得留下的表达；也可以练习雅思口语 Part 2。

这是**个人本地版**：学习记录与录音保存在浏览器，使用你自己的模型 API 账户。当前接入豆包实时语音与百炼 qwen-plus；不是离线 AI，也不提供公共服务器或自动云同步。

## 五分钟开始

1. 从 [Node.js 官网](https://nodejs.org/en/download) 安装 **Node.js 24 LTS**（包含 npm）。本轮使用 Node 24.19.0 测试。
2. 下载仓库 ZIP 并解压，或者使用 Git 克隆。进入包含本 README 和 `package.json` 的文件夹，在终端运行：

   ```sh
   npm run setup
   npm start
   ```

   `setup` 按 `qwen-probe/package-lock.json` 安装锁定依赖，没有 Python、数据库或 Docker 依赖。首次安装需要网络。
3. 保持终端运行，浏览器打开 [http://127.0.0.1:53219/](http://127.0.0.1:53219/)。停止时在终端按 `Ctrl+C`。以后只需运行 `npm start`。
4. 打开「AI 服务设置」，填入你自己的凭据并保存，然后开始练习。不要把 Key 提交到仓库、Issue、截图或公开备份。

Windows 可在解压文件夹中打开终端／PowerShell，macOS／Linux 在终端进入该目录。若 PowerShell 阻止 `npm.ps1`，可改用 `npm.cmd run setup`、`npm.cmd start`，不需要关闭系统执行策略。浏览器推荐近期版本的 Edge／Chrome；其他浏览器及操作系统尚未逐一真实验收。

[config.example.json](config.example.json) 仅解释页面字段，含假占位值，程序**不会自动读取此文件或 `.env`**。请直接在本机页面输入凭据。

## 两条练习流程

**听后聊：** 导入英文素材 → 播放并选择片段 → 确认英文内容 → 开始实时聊天 → 主动语音复盘或结束后看文字版。英文字幕默认收起，中文按需生成；没有字幕时，粘贴所选片段的英文或导入 SRT／VTT／TXT。纯片段文本最多 12000 字符。本地音视频最多 50 MB。

目前解析 TED 页面、NPR／BBC 公开 RSS 和限定来源媒体直链。已实际解析的 [TED 示例](https://www.ted.com/talks/celeste_headlee_10_ways_to_have_a_better_conversation) 与 [NPR RSS 示例](https://feeds.npr.org/510351/podcast.xml) 可取得媒体信息，但该次未取得字幕，需要补英文后才能聊天；解析成功不保证用户所在地可播放。NPR RSS 选择首个完整条目。YouTube／B站暂不直接解析，可以使用自己有权使用的本地文件和英文字幕。

**Part 2：** 内置原创题卡／自添题卡（最多100张，可选中后删除） → 60秒准备与笔记 → 主动开始最多120秒独立作答 → 最多两个短追问 → 语音／文字复盘。独立作答不会因思考停顿交卷，AI 等提交后回应。同题重练建立新记录。

当前复盘可评转写中的词汇、语法和组织，提供原句证据与表达建议。**原音发音评测及雅思总参考分尚未接入**，不是官方雅思评分工具。接话等待可选1.5／3／5秒；句中停顿误接话仍需真实体验调优。

## 记录、备份与迁移

「练习记录」可以回看原音、下载录音和复盘；「表达复习」可停止安排、恢复或删除自动整理的建议。

在「练习记录」导出备份，再在另一份本地安装中导入，可以手动搬迁记录。备份含原音、文字、复盘、题卡和复习策略，不含模型配置。导入采用**追加方式，同ID的本机记录保留，不覆盖**；已停止／删除的表达不会被旧备份自动重新安排。备份上限100 MiB，包含的音视频合计最多64 MiB；超限需减少本地大素材或分开保存原音，不会默默丢掉录音。

备份不是加密文件，含你的练习内容，请自行妥善保存，不要上传公开仓库。没有自动手机／电脑同步。端口、浏览器和 `127.0.0.1`／`localhost` 不同会形成不同存储空间；清除浏览器数据前先备份。刷新后Key清空，记录仍保留。存储失败会提示；意外退出前最后一小段的保存不作保证。

## 当前运行边界

本地服务只监听回环地址，一次允许一个活动通话，适合个人自部署。手机里的 `127.0.0.1` 指向手机自己；当前版本不承诺手机直接访问电脑使用。不要把服务直接绑定公网当作多用户网站。下一阶段若提供公开在线版，需要独立的账户、会话隔离、HTTPS和并发改造。

本项目没有后台上传学习记录或产品遥测；实时练习仍会把声音／上下文发送给你选择并配置的模型服务商。详细数据流见 [PRIVACY.md](PRIVACY.md)。源音视频由浏览器从相应来源播放；默认不把整段源视频托管到项目服务器。

## 开发、检索与评测

```sh
npm test
npm run check
npm run knowledge:build
npm run eval:knowledge
```

自动测试使用假模型／设备；部分用真实本地回环HTTP／WebSocket，所以需要允许本机监听。通过这些测试不等于真实模型的延迟、发音或教学效果通过。

表达复盘使用64张原创卡、来源索引和显式关系图，检索为BM25＋规则＋一跳关系扩展；不是向量数据库。最多检索4卡／6000字符，语音和文字复盘共用同一冻结建议。即时求助没有逐轮动态RAG接线。详见 [知识与评测说明](docs/knowledge/README.md)。

目录中的 `qwen-probe` 是实现目录，保留早期诊断和测试模块；正常使用始终从根目录 `npm start` 进入产品。维护者可用 `npm run release:prepare` 构建新的干净发布目录，已有非空输出不会覆盖，可加 `-- --output release/afterword-v2` 指定新目录，模板在 `open-source/`，输出文件见 `RELEASE-MANIFEST.json`。仓库CI已配置；发布前需实际运行，不能把配置文件当成CI已经成功。
