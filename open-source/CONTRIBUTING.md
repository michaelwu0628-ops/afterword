# 贡献

安装Node.js 24，运行 `npm run setup`、`npm test`、`npm run check`。从根目录 `npm start` 启动个人本机版本。

修复行为时添加能复现问题的测试；模型和设备使用假实现，不能用维护者或用户的实际Key做自动测试。保持回环监听、同源校验、会话清理、凭据只在内存和无伪造学习数据的边界。不要把本地版直接扩成公网多人服务。

知识卡必须是自己的说明和例句，登记支持主张与来源链接。不得加入付费课程、整段视频字幕、完整官方评分表或没有再分发依据的教材原文。正确的简单英语不应为了显得高级而被判错；可选表达与明确问题分开，原句证据要能定位。

问题反馈写明复现步骤、预期／实际行为、Node和浏览器版本、错误码。不要上传Key、Access Token、账号资料或未授权的他人录音。备份文件也含私人练习内容。

新贡献按本项目MIT许可证提供。外部依赖和来源的许可需分别保留，提交前检查 `THIRD_PARTY_NOTICES.md`。
